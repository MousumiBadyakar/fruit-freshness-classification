# 🍎 Fruit Freshness Classification

A deep learning-based image classification web application that detects whether a fruit is **Fresh** or **Rotten** from an uploaded image.

The project uses a trained TensorFlow/Keras model and provides an interactive interface built with Streamlit.

## 🚀 Live Demo

🔗 **[Try the Live Application](https://fruit-freshness-classification-fmsifapqpthbchzegmnoic.streamlit.app/)**

## 📌 Project Overview

Fruit quality assessment is an important task in food processing and retail. This project demonstrates how deep learning can be used to classify fruit images based on their freshness.

Users can upload an image of a fruit, and the trained model predicts whether the fruit is **Fresh** or **Rotten**, along with the prediction confidence.

## ✨ Features

- 📤 Upload fruit images in JPG, JPEG, or PNG format
- 🧠 Deep learning-based image classification
- 🍏 Fresh / Rotten prediction
- 📊 Prediction confidence display
- 🎨 Interactive Streamlit interface
- 🌐 Deployed as a web application

## 🔄 How It Works

```text
Upload Image
     ↓
Image Preprocessing
     ↓
Resize to 224 × 224
     ↓
Normalize Pixel Values
     ↓
Trained Deep Learning Model
     ↓
Prediction
     ↓
Fresh / Rotten + Confidence
```
